Questions

Is my contact data uploaded anywhere?

No. The browser kit runs entirely on your computer. Nothing is sent to us or anyone else.

What file types does it accept?

CSV and TSV exports from spreadsheets, CRMs, form tools and ad platforms. It detects commas, semicolons, tabs and pipes automatically.

Does it work outside the US?

Yes. Pick your default country code and phone numbers are formatted to the international standard. Numbers that already have a country code are left as-is.

What happens to rows it can't fix?

Rows with no valid email or phone go into a separate review file with a note on each. Rows that can still import but have a smaller problem (like a bad phone number when the email is fine) import with a "Prep Notes" column so you can fix them later.
