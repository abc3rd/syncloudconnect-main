# The engine beneath SynCloud Connect is named Optiq

SynCloud Connect stays the name Clients and Customers see; the hidden engine beneath it (UCP, the Agents and the data) is called Optiq. We picked Optiq over Arc because it carries the Q brand thread (QR, QRAPID, TYRQ) and "Arc" is already crowded as a software name (the Arc browser, Intel Arc). Renaming SynCloud Connect itself was rejected because its domains, apps and Play Store listings already use it. A trademark search is still to be done before Optiq is used in public.
