# The Stars Club is platform-owned and never discounts a sale

The Stars Club is one program across SynCloud Connect, owned and priced by Omega UI and shown under each Client's name. Its income goes to Omega UI, not the Client, and Stars never reduce the price of a sale: Members get value from Stars and Paid Member perks (such as priority delivery), not from discounts. We chose this so the club never eats into a Client's margin and every Client's Customers join the same program; it is costly to reverse once Members have signed up.

## Considered Options

- **Tier discounts (Bronze 0% → Platinum 15%)**: the earlier SCR checkout did this. Rejected because it cuts the Client's margin on every sale.
- **Each Client runs and prices its own club**: rejected; the club is an Omega UI product, and one program is simpler to sell and support.
